# n8n-ai-email-agent
AI-powered email automation built using n8n and OpenAI.
This project is an AI-powered email automation workflow built with n8n. Users provide the recipient, subject, and message through a chat interface. OpenAI generates or refines the email, and Gmail sends it automatically.
Features
✅ AI-generated emails

✅ Gmail integration

✅ Chat interface

✅ Automated workflow

✅ Easy to customize

Tech Stack
n8n

OpenAI

Gmail API

JavaScript

HTTP Requests

How to run

How to Run:

Install n8n
Import workflow.json
Add credentials
Run workflow
